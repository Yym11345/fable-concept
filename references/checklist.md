# 完整自检清单

逐条判定。硬规则不过就必须改；软规则由自己裁量。

## A. 硬规则（机械可查，lint 脚本覆盖大部分）

- [ ] 正文 **≤ 1000 字**（中文字符计）
- [ ] 正文**角色 ≤ 3 个**，最好 2 个
- [ ] 正文**不出现概念名**，不出现该领域术语
- [ ] 正文**无禁用意象**：钟、河流、镜子、迷宫、织布机、地图、灯塔、棋盘、回声、影子、沙漏、风、蜡烛、种子、桥、星辰、蝴蝶、蛛网
- [ ] 正文**无过度文艺化地名**（回声城、记忆之村、遗忘之海、寂静谷一类）
- [ ] 正文**无结构套路**：智者点拨旅人 / 村庄异象顿悟 / 孩童点醒大人 / 师徒辩难 / 临终遗言
- [ ] 正文**无角色黑名单**：钟表匠、图书管理员、隐士、说书人、老船夫、酿酒师、铁匠、抄经人
- [ ] 开头**不落套路**："从前有个地方…""某天某人…""在很远的山里…"
- [ ] 交付含**三部分**：正文 / 概念解析 / 检验问题
- [ ] 解析部分含**映射表**，逐一对应，且落到具体动作或物件
- [ ] 检验问题 **2 个**，且都不是"你怎么看待"式空泛问法

## B. 软规则（需要人读，脚本挡不住）

### 机制层
- [ ] 能用一句**不含术语**的话说出这个概念在做什么动作
- [ ] 故事里**有一个具体的转折**，不是从头到尾一个调子
- [ ] 角色之间的关系/互动本身承载了寓意，不是靠对话传递
- [ ] 故事里**至少一个细节是"可验证的细节"**（具体数目、具体物件、具体时间点），不是氛围描写

### 叙事纪律
- [ ] 角色**没有跳出来当解说员**（搜"因为""所以""这意味着""你看"）
- [ ] 结尾**不是金句**（搜"终于明白""原来""这就是…的意义""终于懂了"）
- [ ] 结尾**停在动作或代价上**
- [ ] 没有多余细节（映射表里找不到对应的细节，删掉）

### 读者层
- [ ] 读完能复述机制，但说不出术语 → 说明概念被裹住了
- [ ] 读到结尾有"啊，是这个"的感觉，而不是"哦，讲的是X" → 说明是寓言不是说明文
- [ ] 第二遍读不啰嗦

### 解析层
- [ ] 定义说清了"属于哪个流派/学科"
- [ ] 映射表覆盖概念的全部核心要素，不只是"整体象征"
- [ ] 每条映射都指得出**具体元素**，不是"象征了复杂性"这类空话
- [ ] 有至少一条映射说明**为什么这个元素能承载这一部分**（机制层面的对应，不是联想）

### 检验层
- [ ] 理解检验：换掉一个设定，机制还成立吗？答案必须是机制性的
- [ ] 迁移检验：给了新场景，读者知道"会在哪一步出现"
- [ ] 两个问题都能**具体作答**，答案不需要重讲一遍故事

## C. 交付前最后一眼

- [ ] 第一部分没有加标题、没有引导语、没有"寓意是"
- [ ] 三个部分的分隔清楚（用"第二部分：概念解析""第三部分：检验问题"这样的标题）
- [ ] 故事读起来**像故事**，不是三段论
