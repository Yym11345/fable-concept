# 范例

## 范例 A：合格范例（概念 = 边际效用递减）

### 第一部分：寓言正文

卖鱼的女人在摊子边上放一只铁盆，盆里是早上剔下来的鱼头。这是她的老规矩，倒掉也是倒掉。

猫来得准时，蹲在盆边，尾巴盘在脚上。

第一个鱼头，它吃得很快，骨头都嚼了。第二个，慢下来，剩下半边鳃。第三个，它叼起来，放下，又叼起来，最后还是吃了。第四个，它闻了很久，转身走开，蹲在两尺外看着盆。

盆里还剩六个。

女人以为是鱼头不新鲜。她从案板上另取一条刚到的鲈鱼，现剔下头，扔进盆里。猫走过来，闻了闻，又走开了。

她把盆往猫跟前推了推。猫站起来，跳上墙头。

女人愣了一会儿，从案板底下摸出一小把虾皮——那是留着给客人试味的。她捏了一撮，撒在地上。

猫从墙头跳下来，吃得干干净净。

后来她养成一个习惯：每天收摊前，把当天没卖完的东西各捏一点，分作几堆摆在盆边。鱼头一堆，虾皮一堆，碎虾一堆，鱼籽一堆。

猫每堆只吃第一口。

她算过账：这些零碎加起来，比一条整鱼贵。

### 第二部分：概念解析

**概念**：边际效用递减（law of diminishing marginal utility），属于**微观经济学**中的**消费者行为理论 / 效用理论**（utility theory），是边际革命（1870 年代，杰文斯、门格尔、瓦尔拉斯）确立的核心命题之一。

**核心定义**：在其他条件不变时，消费者对**同一商品**的**连续**消费，每增加一单位所带来的效用增量（边际效用）会逐次递减；降到零之后，继续增加消费会带来负效用。三个限定条件缺一不可：同一商品、连续消费、其他条件不变。

**元素映射**：

| 故事元素 | 映射到概念 |
|---|---|
| 铁盆里始终是同一种鱼头 | 前提一：同一商品，刺激恒定 |
| 一口气吃下去，中间没有间隔 | 前提二：连续消费，效用来不及重置 |
| 快 → 慢 → 犹豫 → 走开 | 边际效用逐次递减，直至为零 |
| 第二个"剩下半边鳃"、第三个"叼起又放下" | 递减的是**增量**，不是总量——总量一直在增加，增加带来的满足在减少 |
| 盆里还剩六个 | 总供给充足，但边际效用已经为零，多给的都浪费 |
| 换成刚到的鲈鱼、现剔的头（更新鲜） | 换了品质，**商品种类没变**，所以递减照旧——故事里最容易被忽略的一步 |
| 一小把虾皮（换了商品） | 效用重置：换商品，边际效用回到高位 |
| 猫吃得干干净净 | 重置后的高边际效用，与前面"闻了闻又走开"形成对照 |
| 女人"以为是鱼头不新鲜" | 消费者会把边际效用下降误判为品质下降——这是递减规律最常见的误读 |
| 每堆只吃第一口 | 递减在每一个商品内部重新开始，一次也没被绕过 |
| 零碎加起来比一条整鱼贵 | 递减的**代价**：要维持同样的满足，必须不断更换商品，成本随之上移 |

**为什么"换了更新鲜的鱼头还是不吃"这一步最关键**：它把"递减"和"品质下降"切开了。如果故事只写"猫越吃越少"，读者会以为是鱼坏了。加上这一步，读者才被迫去找另一个解释——而那个解释就是机制本身。

### 第三部分：检验问题

1. **理解检验**：女人把鱼头换成刚到的鲈鱼头，猫还是不吃。假设她换的不是鲈鱼头，而是一整条鲈鱼，请预测猫的反应，并说明你的预测依据故事里的哪一步。**再进一步**：如果她把六个鱼头分成三份，隔三个小时各放一份，猫会吃几个？这和你刚才的判断冲突吗？

2. **迁移检验**：一家奶茶店发现老顾客来得越来越稀。老板做了两件事：① 把茶叶换成更贵的；② 每月上一款季节限定。请指出这两件事分别对应故事里的哪个动作，并预测哪一件能让老顾客回来、为什么另一件不会。

## 范例 B：失败范例（附失败原因）

### 失败正文（节选）

从前有个叫落雁镇的地方，镇口有一座钟楼。老钟表匠姓陈，年过七十，独自守着那座钟。镇上的年轻人都说他固执。有一天，一个迷路的旅人敲开他的门，问："老先生，这世上的钟为什么有的准有的不准呢？"老钟表匠笑了笑，说："孩子，你想多了。世间万物皆有其时。"

……旅人走后，老钟表匠打开那口老钟的后盖，看着钟摆慢慢停下。他自言自语道："原来如此。"然后他转身走了，留下一座不再报时的钟楼。

### 失败清单

| 检查项 | 结果 | 说明 |
|---|---|---|
| 字数 | ✗ 不足且松散 | 中段用"……"省略，本质是扩不到 1000 字 |
| 角色数 | ✗ 4 个 | 钟表匠、旅人、"镇上的年轻人"、"孩子" |
| 意象黑名单 | ✗ 钟、钟楼、钟摆 | 直接违规 |
| 角色黑名单 | ✗ 钟表匠 | 直接违规 |
| 结构套路 | ✗ 智者点拨 + 异象顿悟 | 双重违规 |
| 开头黑名单 | ✗ "从前有个叫……的地方" | 直接违规 |
| 术语泄漏 | ✓ | 这条没漏 |
| 角色当解说员 | ✗ | "世间万物皆有其时" |
| 结尾金句 | ✗ | "原来如此" |
| 机制承载 | ✗ | **根本没说清机制**——"有的钟准有的不准"和边际效用无关，只是钟摆停了 |
| 映射表可写性 | ✗ | 写不出不空泛的映射——因为故事没讲机制 |

**最致命的是最后两条。** 这个故事读起来顺，但换成"复利""机会成本""沉没成本"任何一个概念都能套——说明它讲的不是任何具体机制，只是一层"固执老人"的氛围。黑名单违规是显性的、可以照着清单改；机制缺失是隐性的，也是更致命的：改完黑名单，故事仍然是一具空壳。

**修法**：回到概念拆解，先写出"机制"那一行（"同一商品的连续消费，每一单位的效用增量递减"），再问：哪个具体场景里，**同一个动作重复三次而效果一次比一次弱**？答案会指向一个具体的摊位、一个具体的班次、一只具体的动物——而不是一座钟楼。

## 范例 C：同一概念的第二条路子（概念 = 沉没成本）

同一个概念可以有很多条路。下面是"沉没成本"的两条不同选型，用来说明**选型决定上限**。

| | 路子一（差） | 路子二（好） |
|---|---|---|
| 选型 | 一个人买了一张很贵的票，演出不好看，他还是看完了 | 一个夜班分拣员把一件坏掉的扫码枪修了四次，第五次还在修 |
| 问题 | "看完演出"这个动作太被动，读者只能看到结果，看不到决策 | 每一次"修"都是一个可数的决策点，读者能数出四次错误判断 |
| 机制可见度 | 低——需要旁白解释"他舍不得" | 高——不用解释，读者自己会数 |

**结论**：选型时要问"这个场景里，机制能被**数出来**吗？"能被数出来的场景，比只能被"感觉到"的场景强一个量级。
