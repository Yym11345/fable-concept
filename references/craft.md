# 手法参考：概念 → 寓言

## 一、概念收窄

不是所有概念都能直接寓言化。三种常见的"不能直接写"与处理方式：

| 问题 | 例子 | 处理 |
|---|---|---|
| 概念太宽，没有单一机制 | "成长""沟通""创新" | 收窄到其中一个机制："成长"→"反馈如何被放大" |
| 概念是方法论而非现象 | "如何提问""复盘" | 转成"方法用错时世界会怎样"，写成反面案例 |
| 概念依赖术语定义才能成立 | "协方差""同态映射" | 换成现象："两个东西一起变"→"两只猫总在同一时间开冰箱" |

收窄的检验：能否用一句**不含术语**的话说出机制？如果能，寓言就有了。

## 二、场景选型的三条路子

### A. 角色即机制

机制本身有"倾向"时，把倾向变成角色的动机，让它撞上现实。

- 机制："每加一个关注者，后续每个关注者都更愿意来。"
- 角色：一家只做一件事的小店，越火越把客人往彼此怀里推，客人于是来得更多。
- 关键：**角色的行为必须看起来是"它想这么做"，而不是"它在演示这个概念"。**

### B. 流程即舞台

现代职业的具体流程最容易把抽象机制"具体性化"。可用流程清单：

- 理赔员：查勘 → 定损 → 核保 → 赔付
- 电梯保养工：困人 → 维保 → 换件 → 复检
- 分拣员：扫码 → 分流 → 上架 → 交接
- 夜班护士：交班 → 巡房 → 记录 → 抢救
- 外卖站长：派单 → 催单 → 申诉 → 结算
- 二手房中介：估价 → 带看 → 议价 → 签约
- 菜市场摊主：进货 → 定价 → 损耗 → 收摊
- 会计：记账 → 对账 → 调整 → 出表

选流程的标准：**流程里有一步是"人不得不在信息不全的情况下做决定"**——机制就在那里。

### C. 推到荒谬

把机制的边界推到极端，反常处就是它的真形。

- 机制：收益的基数包含之前的收益。
- 荒谬化：银行账户年息 100%，第一年存一粒小麦，第二年变成两粒，第三年四粒……第一百次来取的时候，管理员自己被麦子埋了。

## 三、转折的六种处理

只选一种，用一次。用两种以上会显得作者在炫技。

1. **预期落空** —— 角色以为会怎样，结果不是。
2. **代价延后显形** —— 眼前没事，账在很久以后结。
3. **尺度反转** —— 单看一件小事无意义，放大十万倍才看出规律。
4. **视角翻转** —— 换一个人看同一件事，意义相反。
5. **同义反复** —— 同一动作做三次，第三次忽然有了新意。**这是做结尾的首选。**
6. **物体自己说话** —— 让机制承载物自己开口（一个账户、一张表、一台机器的自述）。

## 四、结尾的六种落法

结尾不停在金句上。停在一个动作或一个具体的代价上。

| 落法 | 例（概念：沉没成本） |
|---|---|
| 停在动作 | 他把票撕了，还是走了出去。 |
| 停在数字 | 那天他一共花了 43 块，其中 40 块买的是已经不能退的东西。 |
| 停在别人的反应 | 收银员扫了第七次那张票，什么也没说。 |
| 停在重复 | 他又看了一眼第三排的位置，还是坐下了。 |
| 停在缺席 | 演出结束后，那把椅子空着，像从没被用过。 |
| 停在物 | 那半张票在他口袋里，一整个冬天都没再拿出来过。 |

**禁止**：出现"他终于明白了……""这就是……的意义""原来……"这类解说句。

## 五、替身意象替换表

黑名单意象不是不能表达对应意思，是不能直接用那个词。用下面这些：

| 想表达 | 黑名单说法 | 替身 |
|---|---|---|
| 时间流逝 | 时钟、沙漏、星辰 | 班次表、打卡记录、保质期、换班铃 |
| 自我认知 | 镜子、影子 | 工牌上褪色的照片、交接本上的旧签名 |
| 信息在传递中变形 | 回声、蛛网 | 二手转述的口头通知、交接群里的消息记录 |
| 路径与岔口 | 迷宫、桥、棋盘 | 分拣台上的岔道、口头申请的转接单 |
| 秩序与混乱 | 织布机、灯塔 | 货架编号、值班表、关卡 |
| 长期积累 | 种子、风 | 一批入库的货、新员工试用期 |
| 自我消耗 | 蜡烛 | 夜班灯、值班台上的小灯 |
| 形态与对称 | 蝴蝶 | 折叠标签的纸样 |

## 六、常见失效模式与修法

| 失效 | 症状 | 修法 |
|---|---|---|
| 概念讲台 | 角色开口讲道理 | 删掉所有"因为…所以…"，把道理改成对方的**动作后果** |
| 情节漂亮但没信息 | 读着爽，说不出讲了什么 | 回到第一步，重新确认"机制"那一行，再重写 |
| 术语藏在细节里 | 没点名却用了"边际""回报"这类词 | 全部换成现象描述："多给一份，第二个就没那么想要了" |
| 角色在替概念说话 | 角色表达超出现实身份 | 换成同行之间的一次分歧或交易 |
| 结尾金句 | 最后一句是总结 | 删掉最后一句，用倒数第二句的**重复**收尾 |
| 映射表里有空项 | 故事里有细节映射不到概念 | 删那个细节，或调整映射 |

## 七、微观尺度的取材表

小场景比大场景更容易"裹住"概念。

- 一次门诊：候诊的人、叫号、复诊的人认不认识医生
- 一通电话：打通没打通、中间转接、对方已经换了岗位
- 一次拆卸：把一个整体拆成零件，发现某个零件不见了
- 一次交易：报价、还价、成交、事后发现价签写错
- 一次交接：两班人交接时漏掉的一句话
- 一次退货：东西退回来了，但退回的用途变了
- 一次清点：数了两遍，两遍不一样
- 一次误判：把 A 当成 B，导致后面一连串都对不上
